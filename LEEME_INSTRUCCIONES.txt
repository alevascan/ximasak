1. ESTRUCTURA DEL PROYECTO
--------------------------------------------------------------------------------
• backend/                 : Proyecto Spring Boot 3.5 con Java 21.
• XIMASAK angular/ximasak-app/ : Proyecto Frontend en Angular 17.

--------------------------------------------------------------------------------
2. REQUERIMIENTOS Y DEPENDENCIAS
--------------------------------------------------------------------------------
• Java JDK 21 (incluye wrapper mvnw.cmd, no requiere instalar Maven aparte).
• Node.js v18+ y npm.
• MySQL o MariaDB (puerto 3306).

--------------------------------------------------------------------------------
3. PASOS PARA EJECUTAR EL SISTEMA
--------------------------------------------------------------------------------

PASO 1: BASE DE DATOS
  - Abre phpMyAdmin o tu cliente MySQL (puerto 3306, usuario 'root', sin contraseña o la de tu equipo).
  - Crea la base de datos llamada: ximasak
  - Importa el archivo: ximasak_full\ximasak_bd_final.sql

PASO 2: BACKEND (SPRING BOOT)
  - Abre una consola dentro de la carpeta: ximasak_full\backend
  - Ejecuta:
      .\mvnw.cmd spring-boot:run
  - El backend iniciará en: http://localhost:8080

PASO 3: FRONTEND (ANGULAR)
  - Abre una consola dentro de la carpeta: XIMASAK angular\ximasak-app
  - Ejecuta:
      npm start
  - La aplicación web estará disponible en: http://localhost:4200
